## The file is not DIMACS

`509_parts.vtx` is a list of 509 points in **Mathematica syntax**, one per line:

```
{0, 0}
{(-5 + Sqrt[33])/12, (3*Sqrt[3] - Sqrt[11])/12}
```

There is no header and no edge list. The graph is the set of pairs at distance
exactly 1. Any pipeline that expects `p edge N M` will silently parse zero
vertices. `tools/verify_509.py` builds the edges from coordinates at 50 digits.

## Why this matters

This is the first time the repo's exact arithmetic has been exercised on a
500-vertex object rather than a 7-vertex toy. It establishes:

1. the coordinate source is correct and reproducible;
2. our unit-distance predicate survives 129,286 pairwise checks with a worst
   deviation of `1e-49`;
3. the baseline is real: this graph is 5-chromatic, so any target must be
   strictly stronger.

It does **not** produce a 6-chromatic graph. It clears the prerequisite.

## What it unlocks

`plan/hadwiger-nelson.md` step 2 is done. Step 3 is the one that matters:
re-run gluing with **forced-equality** bookkeeping. The previous `glue2.py`
saturated at χ=4 because it glued geometry without carrying the diamond's
equality constraint. Geometry was never the missing piece.
