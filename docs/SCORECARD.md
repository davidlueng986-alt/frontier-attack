# Scorecard

Honest odds, the exact object that would settle each problem, and the rule that
kills a branch. Updated 2026-11-02.

## What counts as a hit

| Problem | Hit | Not a hit |
|---|---|---|
| Hadwiger–Nelson | a finite unit-distance graph with χ = 7 (⇒ plane is 7-chromatic), or a verified 6-colouring of the plane | a 6-chromatic graph (that only proves χ ≥ 6, already known) |
| Planar Jacobian | a degree-2 map with det JF = const ≠ 0 and two distinct points with the same image | a constant-Jacobian map with no collision |
| BSD | E/ℚ with rank ≠ ord_{s=1} L(E,s), both computed by independent backends | a numerical near-zero of L that might be rank 2 |

## Specialisation by problem

### 1. Hadwiger–Nelson

- **Cartographer space**: unit-distance graphs generated by (a) circle
  intersection growth, (b) rigid edge-gluing of the Moser spindle, (c) SAT over
  lattice subsets with algebraic coordinates.
- **Cheap filter**: DSATUR upper bound + greedy lower bound. Only run exact
  chromatic number when greedy ≥ 4.
- **Kill criterion**: a generator that has produced 500 graphs with max χ = 4
  is dead. The distribution is the problem.
- **Known wall**: gluing the spindle cannot exceed χ = 4. Reaching 5 requires a
  new gadget (de Grey's H-graph), not more glue. This is exactly the kind of
  fact the Cartographer must surface before compute is spent.

### 2. Planar Jacobian

- **Cartographer space**: Newton-polygon strata of degree-d Jacobian pairs.
- **Cheap filter**: det must be constant; that is a linear system in the
  coefficients for fixed support.
- **Kill criterion**: if a stratum's solution set is entirely triangular
  (composition of elementary maps), it is invertible by construction. Drop it.
- **Known wall**: the quadratic box is provably empty (Wang 1980). Enumerating
  it is a calibration test, not a search.

### 3. BSD

- **Cartographer space**: twist families of a fixed curve, ordered by conductor;
  curves with large rank and small conductor.
- **Cheap filter**: root-number parity, discriminant ≠ 0, rank sanity.
- **Kill criterion**: any claim whose rank has no independent backend is
  `INCOMPLETE` and is not reviewed.
- **Known wall**: rank computation. An agent cannot outsource this to prose.

## The one metric

```
tangent_tax = tokens_spent / max(1, checker_passes)
```

Median tax per problem is the baseline. A branch at 20× median after 50k tokens
is killed. This is the operational definition of "stop solving side lemmas".
